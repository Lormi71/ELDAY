# ELDAY — сайт голосования

## Как выложить на GitHub Pages
1. Создай репозиторий на github.com (например, `elday`), загрузи все файлы из этой папки.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://ТВОЙ_НИК.github.io/elday/`. Кидай ссылку в сервер.

## Что настроить
- `config.js` — ники номинантов, имена файлов фоток, ссылка Discord-вебхука.
- Папка `img/` — фотки номинантов (квадратные смотрятся лучше всего).

## Как приходят голоса
Каждый голос прилетает в Discord-канал через вебхук. Канал сделай закрытым, чтобы никто не видел чужие голоса.
Защита от повторов простая (по браузеру), её можно обойти. Для своего сервера обычно хватает.
